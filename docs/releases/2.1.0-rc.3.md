# CHttp 2.1.0-rc.3

This prerelease adds schema-generated HTTP applications with typed dependency
injection, reflected method policies, and JSON/XML document adapters shared by
HTTP and RPC.

## Changes

- `chttp_app_target` generates an application library and executable from IDL
  and business implementations. Multiple services/endpoints are mounted before
  listening; no hand-written router or `main.c` is required.
- Service-level `inject(member, Interface, header)` and method-level
  `http(verb, route)` describe dependencies and routes. Deployment supplies
  providers; the host owns graph resolution, construction, receiver binding,
  rollback and reverse-order shutdown.
- All methods of a service share one dependency record; different application
  instances are isolated. Missing, ambiguous and cyclic dependencies fail before
  listening. A shutdown timeout retains providers until requests quiesce.
- Method policies use the typed CMeta Interceptor. JSON/XML bodies and responses
  reuse DataBind plans, including explicit content handling and failure semantics
  in HTTP and RPC adapters.
- Include standalone stateless/injected examples, C/C++ consumers, installed
  package tests and lifecycle/error regression tests.

## Dependencies and migration

Requires SaltsUtils Native 4.3.0-rc.8 (application generator capability version 2)
and the Salts 2.3.0 RC family, with rc.9 as the local validation baseline. CI
resolves the latest matching published SDKs and records their provenance.
Rebuild generated code and consumers against matching RID/profile packages.

The experimental `app_inject` and `app_http` annotation spellings are replaced
by `inject` and `http`. Other annotations, including `app_http_policy`, retain
their names. Existing stateless signatures remain unchanged. Injected services
receive a typed dependency record as their first argument; configuration and
provider implementation remain deployment responsibilities.

The generated host supports synchronous native HTTP execution and application
scope. RPC hosting, deferred executors and Plugin leases use the existing
explicit APIs. Request-scoped injection and injected typed-error/Plugin/Wasm
publication are not supported. Dependencies are never request payload fields.

Rollback restores the matching earlier CHTTP/SaltsUtils SDK pair and generated
sources; services opting into injection must restore their earlier signatures
and explicit hosting.

## Qualification

Local Windows Release passed the full 110-target CHTTP CTest suite before the
annotation rename, then all three focused application tests and five installed
package tests after the rename. Publication additionally runs complete
Linux/macOS/Windows builds and CTests, installed consumer tests, and Android/iOS
build-only SDK jobs before producing the five-RID package. Mobile device
execution and new sanitizer qualification are not claimed.

The cryptographic audit limitations documented in rc.2 remain unchanged.
