# CHttp 2.1.0-rc.6

This prerelease rebuilds the CHttp 2.1 SDK against the coherent TLS dependency
family used by Retro.

## Exact upstream SDKs

- Salts.Native **2.3.0-rc.16**, source
  `6cf093dc053db98bb21b1788eb2fc1ada4df195e`.
- SaltsUtils.Native **4.3.0-rc.11**, source
  `fbb5f3ee19589836ced0f3b98414e71e6dcc1388`.
- Normal SDK restoration uses exact NuGet selectors and verifies the resolved
  versions. The release build packages all supported CHttp targets against this
  single ABI family.

## Runtime compatibility

CHttp code and public APIs are unchanged from 2.1.0-rc.5. The rebuild removes
the mixed Salts ABI that prevented Flowie's secure MQTT client from constructing
a WSS/TLS-capable CHttp client when a newer CNet runtime was loaded beside the
older CHttp binaries.

## Qualification

The release workflow builds and tests the Linux x64, Windows x64, macOS arm64,
Android arm64-v8a and iOS arm64 SDKs. Host builds run the full CTest graph and
installed App/RPC consumers before package publication.
