# CHttp 2.1.0-rc.4

This prerelease fixes installed CMake package dependency discovery after another
package has already resolved Salts or SaltsUtils in the same directory.

## Changes

- Resolve Salts and SaltsUtils with explicit `find_package` calls after clearing
  their cached discovery results. This prevents `find_dependency` memoization
  from skipping a required lookup.
- Preserve discovery through `SALTS_ROOT` and `SALTS_UTILS_ROOT`, including the
  required Crypto component and the existing restricted search paths.

## Dependencies and compatibility

Use SaltsUtils Native 4.3.0-rc.9 or a later matching RC to include the corresponding
Salts dependency discovery fix. CI resolves the latest published Salts 2.3.0 and
SaltsUtils 4.3.0 RC packages and records their provenance.

Public C/C++ interfaces and runtime behavior are unchanged from rc.3. Its
application generation requirements and the cryptographic audit limitations
documented in rc.2 remain unchanged.

## Qualification

Publication requires the existing Linux/macOS/Windows builds, CTest suites and
installed application package tests, plus Android/iOS build-only SDK jobs.
Mobile device execution and new sanitizer qualification are not claimed.
